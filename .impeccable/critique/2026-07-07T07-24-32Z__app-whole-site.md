## Redesign strategy
Color: get body off mid-gray; re-anchor dark- or light-dominant monochrome, reserve sand-500 for large headings/dividers. Commit ONE accent or go pure. Type: keep one sans, pair on contrast axis with distinctive display face. Layout: kill eyebrow-as-grammar; de-duplicate content (curated-3 on home); build a real commodity spec table; art-direct per page; rework map. States: ungate hero, add reduced-motion, form validation/errors/pending, focus-visible system.

## Roadmap
Phase 0 (P0/P1): contrast fix, ungate hero, reduced-motion, form hardening, replace placeholder phone/social.
Phase 1 (P1/P2): resolve accent, re-pair typography, focus system + keyboard map.
Phase 2 (P2): de-duplicate content, per-page art direction, spec table + trim fertilizer grid, rework map.
Phase 3 (P3): image LCP optimization, primary-button usage, polish.
